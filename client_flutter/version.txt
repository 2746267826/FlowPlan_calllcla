## v1.4.4

- 完成 `plan260424.md` 中 P1“信息架构与页面层级整理”的开发侧收口，降低一级页面信息密度。

## v1.4.1

发布日期：2026-04-24

本次重点：
- 修复 Outlook 日程导入的标题、地点、备注和时区问题，并加入完整重同步入口

更新内容：
- Outlook Graph 日程拉取显式请求 `subject`、`body`、`bodyPreview`、`location`、`locations` 等关键字段
- 对缺少完整字段的 Outlook 事件自动补拉详情，避免把空标题、空地点、空备注写入本地
- Outlook 日程正文优先读取 `body.content`，并将 HTML 正文转换为纯文本后写入备注
- Graph 时区从 `Asia/Tokyo` 调整为 `Asia/Shanghai`，修复导入日程整体偏移一小时的问题
- 新增“完全重置已同步的 Outlook 日历本”按钮，可只清空本地 Outlook 日历本与日程缓存，不影响任务本，也不会删除 Outlook 服务器数据
- 移除 Windows 软件置顶弹窗式提醒，仅保留托盘/系统通知提醒
- 新增“全部任务与日程管理”页面，支持统一搜索、筛选、多选、批量删除与批量完成任务

## v1.4.0

发布日期：2026-04-24

本次重点：
- 重构 Microsoft Outlook 个人账号连接链路，切换到 `Authorization Code Flow + PKCE`

更新内容：
- 新增统一的 Outlook OAuth 配置文件，集中管理 authority、authorize endpoint、token endpoint、redirect URI、scope、Graph 时区
- Outlook 登录固定改为 `https://login.microsoftonline.com/consumers`
- redirect URI 固定改为 `https://login.microsoftonline.com/common/oauth2/nativeclient`
- 登录改为生成并保存 `code_verifier`、`code_challenge`、`state`
- 设置页改为“连接 Outlook 日历 + 手动粘贴授权结果 + 提交授权码”的个人账号流程
- 新增授权会话校验，要求同一次登录的 `state` 才能完成换 token
- access token 过期后自动使用 refresh token 刷新
- 新增 `OutlookCalendarService`，补齐读取、创建、更新、删除 Outlook 日程的基础能力
- Graph 日历请求统一使用 `Asia/Tokyo` 时区头
- 强化 AADSTS50020、AADSTS50011、`invalid_grant`、`interaction_required`、`consent_required` 等错误提示
