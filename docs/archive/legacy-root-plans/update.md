# FlowPlan 日常更新记录

本文件用于记录开发过程中的日常更新。它比 `version.txt` 更细，面向开发过程和维护记录；`version.txt` 仍用于面向发布版本的更新摘要。

维护规则：

- 每次完成重要功能、结构整理、体验优化、同步逻辑调整、数据模型调整、发布准备或关键 bug 修复后，应在这里追加更新。

- README 的修缮应参考当前 README 的完整结构和内容风格，不应只追加零散段落。
- 后续开发说明应优先引用 `plan260424.md` 作为计划来源。
