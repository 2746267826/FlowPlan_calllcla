# FlowPlan v1.2.0

发布日期：2026-04-23

## 版本标识

Flutter 应用版本：`1.2.0+120`

Windows MSIX 版本：`1.2.0.120`

图标基准文件：`icon2.ico`

当前仓库已接入的平台图标：Windows、Android

## 本次更新

P5 安卓端任务 / 日程 / 追踪体验补齐完成主线闭环：安卓端正式作为日程查看与操作终端、任务查看与同步终端、追踪导入与展示终端、提醒触达终端继续推进。

平台采集抽象：新增追踪平台来源模型，统一描述 Windows 连续窗口采样、Android Usage Stats 手动导入、键鼠输入能力、完整输入历史能力与权限需求，后续追踪页和服务层不再只散落判断平台差异。

设备标识落库：`activity_records` 增加 `device_id` 与 `platform` 存储能力，并补充索引。Windows 自动追踪与 Android Usage Stats 导入都会把本机设备标识写入活动记录，便于未来跨设备同步和来源筛选。

安卓追踪模式面板：追踪页新增安卓专属状态卡片，明确说明安卓端只在打开应用或手动刷新时读取系统使用记录，不常驻后台，并提供使用情况权限入口和立即导入按钮。

安卓展示语义：安卓追踪继续优先展示应用名，包名仅作为底层技术标识保存；日报摘要在安卓端不再展示键鼠输入卡片，避免移动端出现不适用字段。

移动端布局修正：追踪页历史查询工具栏改为可换行布局，摘要卡片在手机宽度下自动压缩为单列，减少红色溢出和字段挤压；Outlook 同步设置页增加移动端内边距与最大宽度约束，兼容手机和平板阅读。

安卓设置页增强：设置页新增“安卓端状态”，可直接查看 Usage Access 权限、设备标识和移动端同步入口；Windows 托盘、自启动等不适用项继续仅在 Windows 显示。

同步状态入口：安卓设置页提供“移动端同步状态”入口，直接进入 Outlook 同步设置页查看连接状态、同步模式、最近同步结果、诊断和冲突信息。

计划进度同步：`plan260422.txt` 中 P5 已更新为完成状态，`CODEX.md` 已补充本轮安卓端适配记录。

版本链路同步升级：Flutter 应用版本、Windows 回退版本号、MSIX 打包版本、应用内关于页版本常量和根目录发布说明已同步提升到 `v1.2.0`。

## 说明

本版本继续依据根目录 `plan260422.txt`、`CODEX.md`、`implementation_plan.md` 与 `task.md` 推进，重点完成 P5 安卓端日程 / 任务 / 追踪体验补齐。

本轮仍未执行任何 `dart`、`flutter`、构建或静态分析命令。请在本地手动构建验证后，再决定是否进入下一轮 Release 评估。
